### 2.2 算法层 algorithms/（6 项）

> ⚠️ 纯函数，不依赖 Vue/Dexie

| 文件                                       | 作用与主要内容                                                                                                                                                                                                                                                                                                         |
| :----------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `types.ts`                                 | **契约中心**：SchedulingRules（周期、工时前后限、人数上下限、工作日、上班节次、最少连续节数、每日均衡、模式、课程过滤）、Slot、ScheduleInput/Output、AssistantSummary、KeepEntry；DEFAULT_RULES、normalizeRules（含旧配置迁移）、buildSlots、SECTION_TIME 时间表、formatSectionLabel、validateRules/assertRulesValid。 |
| `greedy.ts`                                | **排班主算法**（662 行）：可用性矩阵（课程按节次序号判定占用）→ keep 预占 → 主分配（时段按紧度、候选按延续块/负载/稀缺度/id 排序）→ 修复⇄撤销迭代 → 每日均衡（A 档零损伤 / B 档让位兜底）→ 汇总。                                                                                                                      |
| `dutyConflict.ts`                          | **冲突检测**：判断已写入排班是否落在该助理有课的节次上（与算法同一占用口径），返回含课程名与周次的冲突明细。                                                                                                                                                                                                           |
| `greedy.test.ts`                           | **算法测试**（955 行）：容量与工时硬约束、课程占用、周次、节次编号对齐回归、每日均衡两档策略、个性化节数、规则校验、汇总字段、真实三助理夹具回归、全周期冲突守卫、确定性、性能。                                                                                                                                       |
| `dutyConflict.test.ts`                     | **冲突检测测试**：占用口径一致性、理论/实验课过滤、周次与节次序号换算、与仓储联动的批量删除。                                                                                                                                                                                                                          |
| `__fixtures__/regression-3assistants.json` | **真实数据回归夹具**：3 名助理 + 131 条课程（含节次原文）+ 规则；用于锁定「撤销孤立块后应继续补位」等缺陷案例。⚠️ **注意**：含真实姓名，见文末隐私说明。                                                                                                                                                               |

### 2.3 数据层 db/（7 项）

> UI 访问数据的唯一入口

| 文件                    | 作用与主要内容                                                                                                                                                                                                                    |
| :---------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `schema.ts`             | **表与领域模型类型**：assistant（含个性化节数字段）、course、duty_schedule、config、operation_log、schedule_snapshot；Identity、CourseKind、DutySource 等枚举。                                                                   |
| `database.ts`           | **Dexie 实例与版本迁移**：v1 建表 → v2 时段键格式变更 → v3 节次编号对齐（归档旧排班到快照表 + 记日志 + 清空，不逐行平移键）。                                                                                                     |
| `repositories.ts`       | **六组仓储**：assistant（含学号唯一校验、更新时 undefined 即删除字段、删除时级联清课程与排班）、course（整体替换）、duty_schedule（按周替换/批量删除）、schedule_snapshot、config、operation_log；另含 `now()` 与重复学号错误类。 |
| `importService.ts`      | **课程表导入归档编排**：抽成可单测服务层——已存在则更新姓名/身份、不存在则建档，两分支收口到「整体替换课程表」，保证结果一致与幂等。                                                                                               |
| `repositories.test.ts`  | **仓储测试**：CRUD、学号唯一、级联删除（含排班）、事务行为。                                                                                                                                                                      |
| `importService.test.ts` | **导入服务测试**：新建/更新分支、保留电话 QQ 班级、两分支结果一致、幂等、字段口径不越界。                                                                                                                                         |
| `migration.test.ts`     | **迁移测试**：用「只声明到 version 2」的实例伪造含新旧标签混合的旧库，验证升级不抛错、旧排班归档、其他表保留。                                                                                                                    |

### 2.4 工具层 utils/（11 源码 + 6 测试）

| 文件                | 作用与主要内容                                                                                                                                                                                            |
| :------------------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `sectionOrder.ts`   | **节次序号轴（单一数据源）**：16 节混排序列（1~5、中课1/2、6~10、晚课、11~13）、sectionNumber（课表数字节号）、sectionOrdinal（当日序号）、sectionOrdinalRange（解析「中课1-第七节」）、ordinalOverlaps。 |
| `weekParser.ts`     | **周次解析与格式化**：区间、多段、逗号列表、单周/双周（展开为逐周区间）、weekInRanges 判定；formatWeekRanges 对等差序列折叠回「5-17周(单)」。                                                             |
| `courseParser.ts`   | **课程表 xlsx 解析**：定位表头「学生：姓名(学号)」与学期、A 列 7 个时段块、课程网格逐格解析（理论/实验、周次、节次原文、地点、批次 note）；无法解析的条目进 problems 而非静默丢弃。                       |
| `scheduleExport.ts` | **排班表导出**：构建 xlsx 工作簿（标题、周次/时间、网格、值班明细表）、样式（底色/边框/居中/自动换行）、节次带上课时间、格子「姓名+电话」上下两行；产出二进制（Tauri 保存对话框用）或浏览器下载。         |
| `scheduleGrid.ts`   | **网格骨架**：collectGridKeys/collectGridDays 取「当前规则 ∪ 已写入数据」的并集，修复「改配置后旧数据在界面/导出中隐身」；DAY_LABELS。                                                                    |
| `scheduleDiff.ts`   | **重排前后差异对比**：按周比对，输出新增/移除/保留项，供「重新排班」展示。                                                                                                                                |
| `fileAccess.ts`     | **双环境文件访问**：isTauri 检测 + saveXlsx（系统另存为 + 写文件）+ openXlsx（系统打开 + 读文件）；非 Tauri 返回 false/null 由调用方回退浏览器流程。                                                      |
| `dict.ts`           | **枚举→中文**：身份类型标签与下拉选项。                                                                                                                                                                   |
| `*.test.ts` (6份)   | 各自模块的单测/集成测试。其中 `courseParser.test.ts` 用 samples/ 三份脱敏夹具做 22 项集成测试（含冻结基线、结构不变式与隐私断言）；`scheduleExport.test.ts` 含解压产物的字节级样式断言。                  |
